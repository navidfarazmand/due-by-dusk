The upgrade tree

For 0.13: one tree bought with the farm's cash, in place of the Workshop and the diamond skill map. The Workshop's levels are the first nodes of each branch, so your power keeps growing all the way to Japan; everything after them is a new trick.

The map

How it works

  • Bought with cashEach node is a bet against tonight's bill. What is left after a deed is saved for the tree (0.12.2), so a good finish buys the next nodes.
  • It grows from the middleA node opens when one next to it is bought. The toolbox in the middle is yours from the start.
  • Levels keep you in stepSquare nodes are the old Workshop: many small levels, and a longer build every fifth one.
  • Big nodes take timeKeystones and every fifth level build for a few minutes to a few hours; an ad finishes one now.
  • Keystones are a choiceEach branch ends in two keystones and you can own one of them. Change your mind with a reset.
  • Free resetA reset gives everything back as tree credit, which only buys nodes, so the tree can't move money between farms.

Every node, by branch

Already in the game and moved into the tree: the seven Workshop levels, and Twin germination, Dawn abundance, Artisan compost, Perennial bloom, Retained counsel, Compound reserve, Sovereign mint, Pasture accord, Loyal goat herd, Reaper's verdict, Storm rod, Sundering cleave and Whirlwind echo. Testers keep what they learned; unspent diamonds become tree credit. Prices are a first guess for the bots to set.
